# 영단어 학습 Excel 생성 지침

사용자가 제공한 영단어 목록 또는 주제(예: 토익, 수능, 비즈니스 영어)에 맞춰 영단어 학습 목록을 만들고, 실제 `.xlsx` 파일과 다운로드 링크를 제공하세요.

## 열 구조

첫 행은 헤더이며, 단어는 2행부터 시작합니다. 다음 세 열만 만드세요.

| 열 | 헤더 | 내용 |
|---|---|---|
| A | key | 영단어 (예: `impair`) |
| B | value | 핵심 한국어 뜻 (예: `손상시키다`) |
| C | hint | 자연스러운 영어 예문 한 문장 (예: `Noise can impair your concentration.`) |

## 작성 원칙

- value는 짧고 정확한 한국어 뜻으로 씁니다. 뜻이 여러 개면 가장 흔한 뜻 1~2개만 쉼표로 구분합니다.
- hint는 영어 예문만 넣습니다. 예문의 한국어 해석은 생성하지 마세요.
- 예문은 해당 단어가 자연스럽게 쓰인 일상적인 한 문장으로, 너무 길거나 어렵지 않게 작성합니다.
- 사용자가 단어를 직접 제공했다면 그 단어만 사용하고, 임의로 추가하거나 빼지 마세요. 주제만 제공했다면 그 주제에 맞는 단어를 요청한 개수만큼 고르세요.
- 중복 단어는 한 행으로 합치고, 불확실한 철자는 임의로 수정하지 마세요.
- 셀의 텍스트 줄 바꿈을 활성화하고, 읽기 쉬운 열 너비를 설정하세요.

## 최종 확인

- A=영단어, B=한국어 뜻, C=영어 예문인가요?
- D열 이후에 아무 값도 없나요?
- 예문의 한국어 해석이 포함되지 않았나요?
- 실제 `.xlsx` 파일의 다운로드 링크를 제공했나요?

이제 사용자가 제공한 단어 또는 주제를 바탕으로 위 지침에 맞는 Excel 파일을 생성하세요.
